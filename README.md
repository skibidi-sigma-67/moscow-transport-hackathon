# Система предиктивной аналитики движения наземного городского транспорта

Программно-аппаратный комплекс для предсказания задержек и оценки рисков отклонения от расписания движения городского транспорта на основе потоковой телеметрии. Решение разработано в рамках Хакатона Московского транспорта.

## Описание системы

Данный проект предоставляет масштабируемое решение для потоковой обработки телеметрических данных (включая протокол NDTP), агрегации исторических и поступающих в реальном времени геопространственных параметров, а также генерации высокоточных прогнозов задержек транспорта с применением моделей машинного обучения. 

Основная цель комплекса — оперативное выявление инцидентов, влияющих на регулярность движения, и предоставление диспетчерским центрам предиктивной информации для принятия управленческих решений.

## Архитектура комплекса

Проект разделен на изолированные модули в рамках микросервисной архитектуры:

1. **Backend (Управляющий сервис)**
   - Прием и обработка телеметрии движения транспортных средств.
   - Парсинг и управление актуальным плановым расписанием (включая автоматическую адаптацию временных рядов).
   - Формирование признакового пространства (feature engineering) на основе истории перемещений.
   - Межсервисное взаимодействие с модулем машинного обучения и персистентное хранение результатов.

2. **Machine Learning Service (Предиктор)**
   - Модель на основе градиентного бустинга (CatBoostRegressor), обученная на исторических транспортных данных.
   - Расчет базовых задержек, остаточных отклонений и вероятностей возникновения инцидентов.
   - Классификация уровня риска и определение паттернов аномалий (заторы, отклонение от маршрута).

3. **Frontend (Информационная панель)**
   - Визуализация местоположения транспортных средств на интерактивной карте в реальном времени.
   - Отображение текущих инцидентов, уровня риска и аналитических метрик для диспетчеров.

## Стек технологий

- **Языки программирования:** Python 3.12+, TypeScript.
- **Backend-инфраструктура:** FastAPI, SQLAlchemy, Pydantic, Uvicorn.
- **Machine Learning:** CatBoost, NumPy, Pandas, scikit-learn.
- **Frontend-инфраструктура:** React, Vite, Recharts, Yandex Maps API.
- **Хранение данных:** PostgreSQL, Redis.
- **Среда выполнения и оркестрация:** Docker, Docker Compose, uv (пакетный менеджер).

### Краткий старт (Docker Compose)
Для быстрого запуска в тестовой среде (при наличии настроенного `.env`):
```bash
git clone <repository_url>
cd moscow-transport-hackathon
docker compose up -d --build
```
После запуска основной **Dashboard будет доступен по порту 80** (`http://localhost`).
