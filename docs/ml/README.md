## Дополнительные функции из задания

| Функция | Статус |
| --- | --- |
| Ансамбль моделей | **Реализован.** Взвешенная комбинация трёх CatBoost-моделей (с весами 0,4 / 0,4 / 0,2). |

По умолчанию ML-сервис запускается со стратегией `schedule_ensemble`. Для неё нужны `manifest.json`, `schedule_plan.csv`, базовая модель и модели `model_2`–`model_4` в `ml/artifacts/`. При наличии `route_features` сервис использует их; иначе строит признаки из расписания для совпадающих транспорта, остановки и времени. Если маршрут в расписании не найден, используется базовая модель со статусом `DEGRADED`. Стратегию можно явно переключить на `baseline` через `APP__STRATEGY`.

Проверка на 151 запросе `validate` показала максимальное расхождение между офлайн-ансамблем и предиктором `5,7 × 10⁻¹⁴` с. Она сверяет только численное соответствие реализации; качество на новых данных требует отдельной оценки.
